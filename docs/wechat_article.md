## 我做了什么

作为一个程序员，我用 Python 写了一个**全自动股票信号分析系统**，每天收盘后自动扫描A股全市场，找出符合条件的买入信号。

### 核心能力

**13个技术指标全覆盖**

KDJ、MACD、RSI、布林带、均线、DMI、CCI、ROC... 主流技术指标全部计算，不漏掉任何机会。

**18种信号类型智能识别**

- KDJ金叉/超卖
- MACD金叉/零轴上穿
- RSI金叉/超卖
- 布林带下轨支撑
- 均线金叉/MA20支撑
- DMI金叉
- CCI超卖/零轴上穿
- ROC零轴上穿

每种信号都有明确的触发条件，不是模棱两可的"可能要涨"。

**三重质量过滤**

不是所有信号都值得看。系统会自动过滤：

- **流动性过滤**：日均成交额 > 1亿，换手率 > 1%，量比 > 0.7
- **估值过滤**：PE 0-85，PB 0-9（排除亏损股和泡沫股）
- **质量过滤**：历史成功率 > 60%，近3日出现6种以上不同信号

**最终留下的，都是经过严格筛选的高质量信号。**

## 三个视图，总有一个适合你

### 1. 垂直时间轴视图 — 像刷朋友圈一样看信号

![时间轴视图]

这是系统的**核心视图**，用垂直时间轴的方式展示所有信号。

**基本操作：**

- **鼠标滚轮缩放**：滚轮向上 = 放大（看细节），滚轮向下 = 缩小（看全局）
- **点击选中**：点击任意信号，只显示该股票的所有信号，其他股票自动变淡
- **再次点击取消**：恢复显示所有信号
- **鼠标悬停**：自动弹出详细信息卡片

**每条信号线展示什么：**

系统用**三条线**表示一个信号的完整生命周期：

| 线条 | 含义 | 颜色 |
|------|------|------|
| 左线（高点线） | 信号出现 → 最高价 | 红色系（涨幅越大越深） |
| 右线（低点线） | 信号出现 → 最低价 | 绿色系（跌幅越大越深） |
| 中间方块 | 买入点 | 红涨绿跌，颜色反映当天+次日涨跌 |

**悬停卡片信息（鼠标放上去就能看到）：**

- 股票代码和名称
- 买入日期和价格
- 买入当天涨跌幅（%）
- 第二天涨跌幅（%）
- 最高价日期、价格、持有天数、收益率
- 最低价日期、价格、持有天数、亏损率

**筛选功能（左侧边栏）：**

- 按股票代码筛选（支持模糊搜索）
- 按日期范围筛选
- 按交易热度评分筛选（0-100分）
- 显示/隐藏最高价线、最低价线、买入点
- 显示/隐藏股票名称、收益率数据

**顶部统计面板：**

- 全库概览：总信号数、股票总数、平均成功率、平均最高涨幅
- 当前筛选后：筛选后的信号数、涉及股票、平均成功率、平均最高/最低涨幅

**这个视图的核心价值：一眼看出信号出现后，股价是先涨后跌，还是先跌后涨，还是稳步上涨。**

### 2. 收益矩阵视图 — 用数字告诉你哪个策略最赚钱

![矩阵视图]

这是一个**止盈止损策略回测矩阵**，帮你找到最优的止盈止损参数组合。

**矩阵结构：**

- **行**：止盈目标（5%、8%、10%、15%、20%）
- **列**：止损线（-3%、-5%、-8%、-10%、-15%）
- **单元格**：每个参数组合的回测结果

**每个单元格显示什么：**

```
触达率 85%
止盈 60% / 止损 40%
触发均值 +8.2%
```

- **触达率**：在指定窗口内，有多少比例的信号触发了止盈或止损
- **止盈/止损比例**：触发的信号中，止盈和止损各占多少
- **触发均值**：止盈固定 +X%，止损固定 -Y%，加权平均收益

**颜色含义：**

- 绿色背景：触达率≥60% 且止盈率≥60%（高质量策略）
- 红色背景：触达率≥60% 但止损多（止盈率<40%，危险策略）
- 白色背景：触达率<60%（信号不够集中）

**TOP 10 标记：**

矩阵会自动标记**收益最高的10个参数组合**，帮你快速找到最赚钱的策略。

**这个视图的核心价值：不用自己回测，直接告诉你"止盈10%、止损5%"这种参数组合，在历史上能赚多少钱。**

### 3. 数据列表视图 — 传统表格，精确筛选

![列表视图]

如果你喜欢用 Excel 看数据，这个视图最适合你。

**表格列（全部可排序）：**

| 列名 | 含义 |
|------|------|
| 股票代码 | 如 sh603288 |
| 股票名称 | 如 海天味业 |
| 信号数 | 同一天出现几种信号（越多越强） |
| 成功率 | 历史回测成功率（%） |
| 插入日期 | 信号出现的日期 |
| 插入价格 | 信号出现时的收盘价 |
| 最高涨幅 | 信号后最高价涨幅（%） |
| 最高日期 | 最高价出现的日期 |
| 最高天数 | 持有几天达到最高价 |
| 最低涨幅 | 信号后最低价跌幅（%） |
| 最低日期 | 最低价出现的日期 |
| 最低天数 | 持有几天出现最低价 |
| 买入当天涨跌 | 信号当天的涨跌幅（%） |
| 第二天涨跌 | 信号次日的涨跌幅（%） |
| 热度评分 | 交易热度（0-100分） |

**筛选功能：**

- 按股票代码/名称模糊搜索
- 按信号类型筛选（如只看"KDJ金叉"）
- 按成功率下限筛选（如只看成功率>70%的）
- 按信号数量筛选（如只看3种以上信号同时出现的）
- 按日期范围筛选

**排序功能：**

- 点击任意列标题排序
- 再点一次切换升序/降序
- 默认按创建时间降序（最新的在前面）

**分页功能：**

- 每页20条
- 支持跳转到指定页码
- 显示总页数和当前页

**这个视图的核心价值：精确筛选+多维度排序，帮你从海量信号中快速找到最符合条件的标的。**

## 常见问题

**Q: 这个系统推荐股票吗？**

A: 不推荐。系统只是帮你筛选出符合技术分析条件的信号，最终买卖决策还是要你自己判断。投资有风险，入市需谨慎。

**Q: 数据准确吗？**

A: 数据来自 baostock（证券宝），是专业的A股数据接口。技术指标计算使用 ta 库（Technical Analysis Library），是业界标准的量化分析工具。

**Q: 每天什么时候更新？**

A: 每天收盘后（15:30）自动更新，扫描当天全市场的信号。

**Q: 可以回测吗？**

A: 系统会记录每个信号出现后的价格走势，包括最高价、最低价、持有N天后的涨跌幅。你可以通过历史数据验证信号的有效性。
